# Registration System for Non-Transport Vehicles

A desktop-based management system designed to streamline the registration process for private (non-transport) vehicles. This application focuses on data integrity, record management, and user workflow for vehicle administration.

## 🚀 Features

- **Vehicle Registration:** Interface for capturing owner details, vehicle specifications, and engine numbers.
- **Search & Retrieval:** Query system to find vehicle records based on registration numbers or owner IDs.
- **Data Persistence:** Local storage/database integration for maintaining long-term records.
- **Validation:** Basic input validation to ensure data consistency (e.g., engine number formats).
